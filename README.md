# Expense Tracker (Python + SQLite)

A command-line expense tracker that stores income and expenses in a SQLite database.

## Features
- Add income and expenses with category, amount, date and note
- Input validation for amount and date
- View all transactions
- Balance (total income, total expense, savings)
- Category wise expense summary with percentages
- Monthly summary with highest spending category
- Delete transactions
- Data saved permanently in SQLite

## How to run
1. Install Python 3
2. Download expense_tracker.py
3. Run: python expense_tracker.py

## Concepts used
Python functions, try/except, datetime, SQLite, SUM, GROUP BY, strftime, parameterized queries

## Built with
Python, SQLite (sqlite3 module)
